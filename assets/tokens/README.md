# Original token reference images

These local assets display the source token image alongside SPECIES' original evolved-organism artwork. Retrieved from CoinGecko's image CDN on 4 October 2026. `sources.json` records the exact source URL and token reference page for each asset.

Images and names belong to their respective owners. Their appearance in this local application does not imply affiliation or endorsement. No live token lookup, market request or external image loading occurs when using the application.

RUGRAT, DUST and VOID are fictional reference specimens and have no real original-token reference image. Custom species use their user's uploaded image.
